WAI-ARIA Splitter (role="separator") Accessibility Test

This sample page demonstrates how Chromium treats role="separator" elements differently based on focusability and range attributes.

1. Interactive Resizable Splitter IsRangeValueSupported() == true

Has role="separator", tabindex="0", and aria-valuenow/min/max. Focus the blue divider and use Arrow Left / Arrow Down to decrease, Arrow Right / Arrow Up to increase, or drag with touch/mouse.

Left Panel

Width is bound to aria-valuenow.

Right Panel

Takes remaining flex space.

aria-valuenow: 50%
aria-valuetext: 50 percent
Last Event: None

2. Static Non-Resizable Separator IsRangeValueSupported() == false

A standard <hr> or <div role="separator"> without tabindex="0". Because it is not focusable, Chromium treats it as a static structural divider and does not expose range controls.
